Detailed Description

Implements utility functions for random request generation.

Provides random number initialization and helper functions for generating IP addresses, job types, request processing times, and percentage values for the load balancer simulation.

Function Documentation

◆ init_random()

void init_random ( )

Initializes the random number generator.

Seeds the Mersenne Twister engine using a value obtained from std::random_device and prints an initialization message.

Note
Call this function once before generating random values.

◆ random_ip()

std::string random_ip ( )

Generates a randomized dotted-decimal IP-like address.

Generates four numeric components and joins them with periods. The first component is regenerated if it equals 10, 172, or 192.

Returns
A string containing four dot-separated numeric components.
Warning
The generated components range from 0 to 999, so this function does not guarantee a valid IPv4 address. Valid IPv4 octets must range from 0 to 255.
