Detailed Description

Manages a request queue and dedicated web server pool.

Each instance accepts only one job type: 'S' for streaming or 'P' for processing. Server scaling is performed independently for each instance.

std::string LoadBalancer::adjustCapacity ( int cycle,
int cooldown )

Adjusts server capacity according to queue size.

Scales the pool according to its pending queue size.

Adds one server if the queue exceeds 80 requests per server. Removes one idle server if the queue falls below 50 requests per server, provided at least one server remains.
